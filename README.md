# Primus-Media-Catalog

Primus 影视资源公开目录页。

本仓库仅发布可公开浏览的影片目录信息，包括片名、年份、资源类型、分辨率、动态范围、帧率、视频编码、音频、字幕、原语言、片长、豆瓣评分、TMDB 评分与文件大小。

不在本仓库保存：
- ED2K 链接
- ED2K Hash / AICH
- 115 Cookie / Token / 账号凭据
- 私有分享文案与归档数据

目录中的 **“私有详情 🔒”** 按钮会跳转到 `Primus-Media-Archive` 私有仓库中的对应分享页；只有已登录且被授权访问该私有仓库的 GitHub 账号可以打开。

GitHub Pages 启用后，目录入口为：

```text
https://primus-z-xt.github.io/Primus-Media-Catalog/
```
