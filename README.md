# Primus-Media-Catalog

Primus 影视资源目录，用于整理与展示影片版本信息。

## 在线目录

https://primus-z-xt.github.io/Primus-Media-Catalog/

## 功能

- 按片名、年份、编码、音频、字幕等关键词搜索
- 按资源类型、分辨率、动态范围筛选
- 按上传时间、豆瓣评分、TMDB 评分、年份与中文片名排序
- 展示分辨率、HDR / Dolby Vision、帧率、视频编码、音频、字幕、原语言、片长与文件大小等信息

## 说明

豆瓣与 TMDB 评分为整理时的阶段性快照，可能随用户投票变化。

本项目用于个人影视资源目录整理与版本信息展示。
